
## Fetch.ai: AI Agents League track + overall prizes - appended by dd_chunk_015
Source: https://la-hacks-2025.devpost.com/
Fetch.ai AI Agents League: use Fetch.ai's ASI1-Mini LLM for agent reasoning and build with the uAgents framework or Fetch.ai SDK; target verticals like healthcare, education, finance, sustainability. Sub-prizes: Most Impactful Vertical Solution, Best ASI-1 Mini Implementation, Best Multi-Agent System. Overall prizes 1st-3rd. Judging: originality, impact/usefulness, feasibility within 3-5 years, relation to track. General tracks: Clean Code, Hack2School, Cold Hard Cache, Heart of the Matter.

## LA Hacks 2025 tracks and challenges (official wording, paraphrased) - appended by dd_chunk_041
Source: https://la-hacks-2025.devpost.com/
- Clean Code (Sustainability): "Build like the planet depends on it"; community gardening, shared-resource platforms, eco-friendly living tools.
- hack2school (Education & Productivity): tech that empowers educators and improves student success, from classroom management to AI personalized learning.
- Cold Hard Cache (FinTech): financial literacy, investment platforms, blockchain solutions; "make money move".
- Heart of the Matter (Healthcare): mental wellness platforms, diagnostics, fitness apps.
- Google Gemini: Chase the Future!: Gemini 2.0/2.5 APIs must be the core component; multimodal input, advanced reasoning, code generation, personalization, real-time conversation. 1st $2,000, 2nd $1,000, 3rd $500.
- Snap Inc. Challenge: Dream it. Build it.: create a Lens on Spectacles that pushes wearable AR; themes: AI on AR glasses with camera access, fitness/health, dream worlds, everyday utility. Spectacles plus $3,000/$2,000/$1,000.
- DAIN Challenge: AI Agent Excellence & Innovation Awards: use the DAIN platform and Butterfly client app to build and deploy AI agent services for consumers/businesses, aiming at a profitable AI business. $5,000/$1,500/$500 plus Agent Launchpad.
- Warp Challenge: Best Developer Tool: improve developer experience across creating, modifying, testing software. Keychron keyboards.
- Linkd Challenge: Best Use of Linkd People Search: best interaction layer on a provided search API and database of 350,000 UCLA alumni.
- MSI Lucky's Hackening: teams of 4 using MSI hardware; select UCLA teams only; MSI judges.

## Roblox Civility Challenge; Melissa Data Challenge; Best of Groq - appended by dd_chunk_040
Source: https://la-hacks-2025.devpost.com/
- Roblox Civility Challenge: Building A Better Digital World: use Roblox Cube (Roblox generative AI for 3D/4D) to build experiences that educate others about online safety and well-being. Prizes $2,000/$1,000/$500/$300. No judging criteria listed.
- Melissa Data Challenge: using the Melissa UCLA dataset, plot data on a map and build a solution that finds nearest relevant locations for a community problem, optimizing proximity using Melissa APIs. One winner (~$360 value incl. API credits, office visit).
- Best of Groq: build a creative, interactive multimodal app powered by Groq; judged on number of modalities Groq powers (text, vision, audio), innovation on a real problem, UX and design. $500 cash plus $500 swag credit.

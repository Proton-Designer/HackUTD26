
# HackIllinois 2026 prize text (paraphrased from https://hackillinois-2026.devpost.com/ ; fetched by dd_chunk_026)
## Track: Best AI Inspection (Caterpillar)
Build AI for field operations and logistics that makes inspections, parts identification and site planning smarter, faster, safer. 1st $1,500 + Ray-Ban Meta glasses + pitch to CAT exec; 2nd $700; 3rd $300; 3 honorable mentions. (hackillinois.org/caterpillar_track.pdf)
## Track: Best Web API (Stripe)
Build a well-crafted API emphasizing surface design, developer experience, correctness; clarity, predictable behavior, useful docs. 1st $2,000; 2nd $500. (hackillinois.org/stripe_track.pdf)
## Track: Best AI Inference (Modal)
Build ambitious apps that run inference on Modal (GPU compute, sandboxes, storage) to solve a real-world problem. 1st $2,000 + $5,000 Modal credits each; 2nd $500 + $1,000 credits; 3rd $1,000 credits.
## Track: Best Hardware Hack (John Deere Mechathon), Easy Track
Team that excels at integrating hardware (IoT, robotics): physical computing for innovative solutions and interactive experiences. (hackillinois.org/johndeere_track.pdf)
## Best Use of Actian VectorAI DB
Build an AI application using Actian VectorAI DB (RAG, recommendation, semantic search, real-time AI); quality-gated; feedback to Actian required. 1st $300+$300 cards; 2nd $120+$120; 3rd Anker hubs.
## Best Use of Supermemory
Use Supermemory Context Engineering APIs (retrieval, memory, user profiles, connectors, multimodal extractors) to build an app that remembers, understands and adapts to users. Prize: Meta RayBans.
## [MLH] Best Use of Gemini API
Build AI-powered apps with Gemini API (chatbot, summarizer, generated content). Prize: Google swag.
## Most Creative
Highest originality, imagination, ingenuity; unconventional approaches.
